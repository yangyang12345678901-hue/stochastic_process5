# 第 5 章 马尔可夫链 · 解题技巧与考试要点

> 目标：把"会背定义"升级为"考场上能下笔、不丢分"。本篇给出**题型套路、判别流程、易错点、公式速查与自测清单**。

---

## 一、六大题型与标准套路

### 题型 1：写出（一步）转移矩阵 / Q 矩阵
**步骤**：① 明确状态空间 $S$（边界状态单独想清楚）；② 逐个状态分析"下一步能去哪、概率多少"；③ 检查每行和（离散 $=1$；连续 $Q$ 行和 $=0$）。
- 离散：边界（吸收/反射/弹性）最易错，先画状态转移图。
- 连续：先定每个状态的**离开速率** $q_i$ 和**去向速率** $q_{ij}$，对角填 $-q_i$。

### 题型 2：求 $n$ 步转移概率 / $t$ 时刻分布
- 小矩阵：直接 $P^{(n)}=P^n$；两状态用现成公式或特征值对角化 $P=V\Lambda V^{-1},\ P^n=V\Lambda^n V^{-1}$。
- 求分布：$\pi_n=\pi_0P^n$；连续时间 $p_j(t)=\sum_i p_i(0)p_{ij}(t)$。
- "经过指定路径的概率"：用有限维分布把各段转移概率**连乘**。

### 题型 3：状态分类（可达/互通/周期/常返性）
按 [§5.2 流程图](#二状态分类判别流程图)逐项判定。**先分互通类 → 判每类的周期 → 判常返/正常返**（周期、常返性是类性质，整类一起判）。

### 题型 4：极限分布 / 平稳分布
- **离散**：解 $\pi P=\pi,\ \sum_i\pi_i=1$（$|S|=k$ 时去掉一个方程加归一化，解 $k$ 元线性方程组）。
- **连续**：解 $\pi Q=0,\ \sum_i\pi_i=1$。
- **可逆/生灭结构**：优先用**细致平衡** $\pi_i p_{ij}=\pi_j p_{ji}$（离散）或 $\pi_i\lambda_i=\pi_{i+1}\mu_{i+1}$（连续生灭）逐项递推，远快于解方程组。
- 判 $p_{ij}^{(n)}$ 是否有极限：**遍历 → 有**；**周期 → 无**（只有 Cesàro 平均）；**非常返/零常返 → 趋于 0**。

### 题型 5：吸收概率 / 平均吸收（首达）时间
设 $h_i=$ 从 $i$ 出发被某目标吸收态吸收的概率，**对非吸收态列一次步条件方程**：
$$
h_i=\sum_j p_{ij}h_j,\quad \text{目标吸收态 } h=1,\ \text{其它吸收态 } h=0.
$$
平均吸收时间 $k_i=E_i[\text{吸收步数}]$：
$$
k_i=1+\sum_{j\text{ 非吸收}}p_{ij}k_j,\quad k_{\text{吸收}}=0.
$$
（连续时间把"$1$"换成"$1/q_i$"，把 $p_{ij}$ 换成嵌入链 $\tilde p_{ij}$。）

### 题型 6：分支过程灭绝概率
解母函数不动点方程 $s=\varphi(s),\ \varphi(s)=\sum_j p_j s^j$，取 $[0,1]$ 内**最小非负根**。判据：均值 $m=\varphi'(1)\le1\Rightarrow\pi_0=1$；$m>1\Rightarrow\pi_0<1$。

## 二、状态分类判别流程图

```
给定一条马氏链
   │
   1) 画状态转移图, 按"互通 ↔"把状态分组 → 各互通类
   │
   2) 判每个类是否为闭集?
   │     ├─ 非闭(能漏出去) ⇒ 该类状态【非常返】(瞬过态)
   │     └─ 闭集 ⇒ 继续
   │
   3) 闭集内: 有限状态? 
   │     ├─ 有限不可约闭集 ⇒ 【正常返】(有限链无零常返)
   │     └─ 无限状态 ⇒ 用 Σ p_jj^(n) 判:
   │            Σ=∞ ⇒ 常返; 再用 μ_j=Σ n f_jj^(n) 分正常返(μ<∞)/零常返(μ=∞)
   │            Σ<∞ ⇒ 非常返
   │
   4) 判周期 d(i)=gcd{n: p_ii^(n)>0}:
         有自环 p_ii>0 ⇒ d=1 (非周期)
         否则取所有回路长度的最大公约数
   │
   5) 正常返 + 非周期 ⇒ 【遍历态】
```

**一维随机游走常返性速记**（$p_{i,i+1}=p,\ p_{i,i-1}=1-p$）：
- 无限制（整数轴）：$p=\tfrac12$ → **零常返**；$p\ne\tfrac12$ → **非常返**。
- 带反射壁有限链：不可约有限 → **正常返**；只走相邻 → **周期 2**。

## 三、易错点清单（考前必看）

1. **"平稳分布"≠"极限分布"**：周期链有平稳分布但无极限分布；只有**遍历链**两者相等。
2. **行和方向**：转移矩阵是**行和为 1**（$\sum_j p_{ij}=1$），$\pi P=\pi$ 中 $\pi$ 是**行向量左乘**。别写成列和或 $P\pi$。
3. **$Q$ 矩阵行和为 0**，对角是负的 $-q_i$；求平稳分布是 $\pi Q=0$ 不是 $\pi Q=\pi$。
4. **零常返/瞬过态只存在于无限状态链**；有限链一定有正常返态、绝不含零常返态。
5. **周期是类性质**：同一互通类周期相同，别对单个状态各判一次。
6. **首达概率 $f_{ij}$ vs 转移概率 $p_{ij}^{(n)}$**：$f$ 是"首次"，$p^{(n)}$ 是"第 $n$ 步在不在"，用分解式 $p_{ij}^{(n)}=\sum_l f_{ij}^{(l)}p_{jj}^{(n-l)}$ 连接。
7. **常返判别**用级数 $\sum_n p_{jj}^{(n)}$ 是否发散，不要和 $\lim p_{jj}^{(n)}$ 混淆（常返也可能极限为 0，如零常返）。
8. **连续时间停留时间是指数分布**，参数是 $q_i$（离开总速率），不是某个 $q_{ij}$。
9. **吸收概率方程**要把吸收态的边界值（0 或 1）固定，否则方程组欠定。
10. **归一化别忘**：解出 $\pi$ 成比例后必须用 $\sum_i\pi_i=1$ 定常数。

## 四、公式速查表

### 离散时间

| 名称 | 公式 |
| --- | --- |
| 马氏性 | $P(X_{n+1}=j\mid X_n=i,\dots)=P(X_{n+1}=j\mid X_n=i)$ |
| C-K 方程 | $p_{ij}^{(m+n)}=\sum_k p_{ik}^{(m)}p_{kj}^{(n)},\ P^{(n)}=P^n$ |
| 绝对分布 | $\pi_n=\pi_0P^n$ |
| 首达分解 | $p_{ij}^{(n)}=\sum_{l=1}^n f_{ij}^{(l)}p_{jj}^{(n-l)}$ |
| 常返判别 | 常返 $\iff \sum_n p_{jj}^{(n)}=\infty$ |
| 非常返求和 | $\sum_n p_{jj}^{(n)}=\dfrac{1}{1-f_{jj}}$ |
| 平均返回时间 | $\mu_j=\sum_n n f_{jj}^{(n)}$；正常返 $\mu_j<\infty$ |
| 遍历极限 | $\lim_n p_{ij}^{(n)}=\pi_j=1/\mu_j$ |
| 平稳分布 | $\pi P=\pi,\ \sum\pi_i=1$ |
| 细致平衡 | $\pi_i p_{ij}=\pi_j p_{ji}$ |
| 两状态 $P^n$ | $\dfrac{1}{p+q}\begin{psmallmatrix}q&p\\ q&p\end{psmallmatrix}+\dfrac{(1-p-q)^n}{p+q}\begin{psmallmatrix}p&-p\\ -q&q\end{psmallmatrix}$ |

### 连续时间

| 名称 | 公式 |
| --- | --- |
| 半群/C-K | $P(s+t)=P(s)P(t)$ |
| $Q$ 元素 | $q_i=-q_{ii}=\lim_{t\to0}\frac{1-p_{ii}(t)}{t}$，$q_{ij}=\lim_{t\to0}\frac{p_{ij}(t)}{t}$ |
| 行和 | $\sum_j q_{ij}=0$ |
| 停留时间 | $\tau_i\sim\text{Exp}(q_i)$ |
| 嵌入链 | $\tilde p_{ij}=q_{ij}/q_i\ (i\ne j),\ \tilde p_{ii}=0$ |
| 向后方程 | $P'(t)=QP(t)$ |
| 向前方程 | $P'(t)=P(t)Q$ |
| 形式解 | $P(t)=e^{tQ}$ |
| 平稳分布 | $\pi Q=0,\ \sum\pi_i=1$ |
| 生灭细致平衡 | $\pi_i\lambda_i=\pi_{i+1}\mu_{i+1}$ |
| 生灭平稳 | $\pi_n=\pi_0\prod_{i=0}^{n-1}\frac{\lambda_i}{\mu_{i+1}}$ |

## 五、高效学习方法（导师建议）

1. **建立"离散↔连续"对照表**：$P\leftrightarrow Q$、$P^n\leftrightarrow e^{tQ}$、$\pi P=\pi\leftrightarrow\pi Q=0$、几何停留↔指数停留。两边对照记，记忆量减半。
2. **以图驭算**：拿到题先画状态转移图，互通类、闭集、周期、吸收态一目了然，避免盲目代公式。
3. **吃透 5 个模板模型**：两状态链、带壁随机游走、Ehrenfest 链、生灭过程、M/M/N 排队。考题多是它们的变形。
4. **优先用细致平衡**：凡链是图上随机游走或生灭结构，平稳分布用 $\pi_i p_{ij}=\pi_j p_{ji}$ 递推，比解线性方程组快且不易错。
5. **"判别先于计算"**：先判遍历/周期/常返，决定极限分布是否存在、是否等于平稳分布，再动手算，避免做无用功。
6. **限时刷指定作业**：离散 5.1/5.2/5.6/5.7/5.17/5.18/5.19，连续 5.10/5.13/5.14。每题写清"用了哪条定理"。
7. **自测清单**（合上书能否口述）：
   - [ ] 马氏性的精确表述？时齐的含义？
   - [ ] C-K 方程及 $P^{(n)}=P^n$ 的来由？
   - [ ] 可达、互通、闭集、不可约的定义？
   - [ ] 周期定义与"类性质"？非周期的充分条件？
   - [ ] 常返判别准则 $\sum_n p_{jj}^{(n)}=\infty$？正常返 vs 零常返？
   - [ ] 遍历链定义及 $\lim p_{ij}^{(n)}=1/\mu_j$？
   - [ ] 平稳分布方程 $\pi P=\pi$ 与细致平衡？
   - [ ] 平稳分布何时 = 极限分布？（遍历）
   - [ ] 连续时间 $Q$ 的物理意义、嵌入链 $\tilde p_{ij}=q_{ij}/q_i$？
   - [ ] Kolmogorov 向前/向后方程？$\pi Q=0$？
   - [ ] 生灭过程平稳分布递推、M/M/N 的 Erlang 分布？

## 六、考场答题模板（拿满步骤分）

> **求平稳分布题**通用书写：
> 1. "由题意状态空间 $S=\{\dots\}$，转移矩阵 $P=\dots$（或 $Q=\dots$）。"
> 2. "该链不可约且（有限/正常返/非周期），故存在唯一平稳分布且为极限分布。"（先给判别结论）
> 3. "由 $\pi P=\pi$（或 $\pi Q=0$）得方程组 $\dots$，结合 $\sum_i\pi_i=1$。"
> 4. "解得 $\pi=(\dots)$。"
> 5. （若问极限）"因链遍历，$\lim_n p_{ij}^{(n)}=\pi_j$，与初始状态无关。"

每一步都写出**依据的定理名**，即使最后数值算错，过程分也能保住。
