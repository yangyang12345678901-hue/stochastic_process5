## 全章知识地图

```
马尔可夫链 (无后效性: 将来只依赖现在, 与过去无关)
│
├── 离散时间 (时间 n=0,1,2,...)
│   ├── 基本量: 一步转移矩阵 P, n 步转移矩阵 P^(n)=P^n (C-K 方程)
│   ├── 状态分类: 可达/互通 → 周期 d(i) → 常返/非常返 → 正常返/零常返 → 遍历
│   ├── 极限与平稳: lim p_ij^(n), 平稳分布 πP=π, 遍历链 lim p_ij^(n)=1/μ_j
│   └── 应用: 分支过程、(离散)生灭过程
│
└── 连续时间 (时间 t≥0)
    ├── 基本量: 转移概率 P(t), 转移速率矩阵 Q (Q 矩阵)
    ├── 停留时间 ~ 指数分布; 嵌入链 \tilde P_{ij}=q_{ij}/q_i
    ├── Kolmogorov 向前/向后方程: P'(t)=P(t)Q / P'(t)=QP(t)
    ├── 平稳分布: πQ=0, π·1ᵀ=1
    └── 应用: 生灭过程、M/M/N 排队 (损失制)
```

## 三句话抓住本章核心

1. **马氏性（无后效性）**：$P(X_{n+1}=j\mid X_n=i, \dots, X_0=i_0)=P(X_{n+1}=j\mid X_n=i)$，"未来只看现在"。
2. **离散时间一切计算围绕 $P$**：多步靠 $P^{(n)}=P^{n}$，分布靠 $\pi_n=\pi_0P^n$，长期行为靠平稳分布 $\pi P=\pi$。
3. **连续时间一切计算围绕 $Q$**：转移概率靠 $P(t)=e^{tQ}$（Kolmogorov 方程），平稳分布靠 $\pi Q=0$。

> 把上面 3 句话记牢，本章 80% 的题目都能找到下手方向。
